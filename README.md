# Digital Clock ⏰

A simple and modern digital clock built using HTML, CSS, and JavaScript.

The clock displays the current hours, minutes, and seconds and updates automatically in real time.

## 🚀 Features

- ⏰ Real-time digital clock
- 🕐 Displays hours, minutes, and seconds
- 🔄 Automatically updates every second
- 🎨 Modern gradient UI
- 📱 Responsive design
- ⚡ Built with vanilla JavaScript
- 💻 No external libraries required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

  ## ⚙️ How It Works

 JavaScript is used to get the current time from the user's system and update the clock every second.
 The project uses:
 - setInterval()                                                                                                              to continuously update the displayed time.

##  🎯 Purpose

This project was created to practice:
- JavaScript Date object
- setInterval()
- DOM manipulation
- Dynamic content updates
- CSS styling
- Responsive web design
